ZN SENSI - VERSAO CORRIGIDA

1) Extraia todos os arquivos.
2) Execute INICIAR_ZN_SENSI.bat.
3) Aguarde a mensagem [OK] Servidor online.
4) O navegador abrirá http://127.0.0.1:3000
5) No painel, use um dos usuários autorizados e uma key válida.

PORTA DE ACESSO DO PAINEL: 777

O servidor usa apenas Node.js nativo, sem npm install, Python ou node-gyp.
As 1500 keys permanecem no arquivo protegido KEYS_1500_PROTEGIDAS.zip.
Senha do arquivo protegido: ADMSKEO

O servidor valida as keys por hash, portanto não precisa manter o TXT das keys em texto aberto no diretório do servidor.
As keys de 1 dia ficam vinculadas ao IP de ativação.
A ação INJETAR no painel é apenas uma simulação visual e não modifica ou injeta código em jogos.
